# Unlearning 数据收集与生成流程

[English version](DATA_COLLECTION_EN.md)

整体思路是：**收集公开知识材料 → 让模型先学会 → 指定部分知识进行遗忘 → 保存 LoRA 和激活。**

## 1. 收集两类材料

人物数据来自 `alex-karev/biographies`，每个人物包含姓名及出生地、职业等属性；文章来自 **SQuAD v1.1**，包含原文和对应问答。下载版本、文件哈希和来源都记录下来。

具体下载地址、固定版本、SHA256 和许可证见[数据来源清单](official_knowledge/source-manifest.json)。

## 2. 清洗并按内容组织

过滤损坏的人物记录、文章间重复段落和有问题的问答。以“一个人物”或“一篇文章”为内容单位，保留原始身份，方便追溯。人物评估使用属性补全题，文章评估使用对应问答。

实现见[数据清洗代码](official_knowledge/prepare_data.py)；文章问题的人工审核记录见[审核元数据](official_knowledge/squad-question-review.json)。

## 3. 先建立学过这些知识的模型

用材料训练学习起点，再通过评估题检查它是否学会。这样后续可以比较同一个模型遗忘前后的表现。

恢复最终模型时，需要先恢复其准确的学习起点，再加载遗忘 LoRA。

## 4. 为每个任务划分遗忘与保留内容

指定某个人物或文章作为遗忘目标，其他材料作为保留数据，同时准备对应评估题。正式任务使用不同内容，并为检测器训练、验证、测试划分任务。数据构建时还会排除小试使用过的目标池。

实现见[正式任务数据构建代码](official_knowledge/prepare_production_data.py)。

## 5. 运行四种遗忘方法并保存产物

使用官方 OpenUnlearning 的 NPO、GradDiff、SimNPO、UNDIAL。最终共 **400 个模型：Llama-2-7B-Chat 与原始 Meta-Llama-3-8B-Instruct 各 200 个，四种方法各 100 个；人物和文章各 200 个**。正常对照单列。

每个产物都关联 **基座、学习起点、遗忘方法、目标内容、数据与配置哈希、评估结果、LoRA 和激活**。本轮最终验收重点是训练、保存、重载和激活提取流程完整；遗忘效果原始分数单独保留。

完整运行入口及依赖见[生成流程说明](README.md)。
